IRON ROUTINE – standalone workout tracker

CONTENTS
- index.html: the app
- manifest.webmanifest: installable app settings
- sw.js: offline cache
- icons/icon.svg: app icon

QUICK PREVIEW
Open index.html in a modern browser. Workout logging uses browser local storage. Some PWA features (install and offline service worker) require hosting over HTTPS.

INSTALL ON ANDROID
1. Host the whole iron-routine folder on an HTTPS static host (for example GitHub Pages or Netlify).
2. Open the hosted address in Chrome on Android.
3. Open Chrome's menu and choose Install app (or Add to Home screen, depending on browser/device).
4. Launch IRON ROUTINE from the home screen. Open it online once before using offline so the app files are cached.

DATA
Workout logs and history are stored locally in the browser on that device. Use Progress > Export my data regularly to back up your records. Clearing browser/site data can erase local records.

PROGRESS FEATURES
- Record exercise weight, reps/seconds and completed sets.
- View best recorded working weight per exercise.
- Save dated body-weight and waist check-ins.
- Review recent completed workout sessions.
- Export workout logs, measurements and history as a JSON backup.
